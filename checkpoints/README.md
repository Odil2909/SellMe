# Чек-поинты проекта

- `uyol-before-visual-refresh-zip-2026-11-19.zip` — текущее состояние проекта до применения `uyol-visual-refresh-changed-files.zip`.
- `uyol-before-visual-refresh-2026-11-19.zip` — более раннее состояние до предыдущего визуального обновления.

Архивы содержат исходники, но исключают `.env`, зависимости, сборку и локальные данные сервера. Для отката сначала распакуйте нужный архив в отдельную временную папку и восстановите из неё файлы проекта. Не распаковывайте архив поверх проекта напрямую, если хотите сохранить более поздние файлы и локальные настройки.
